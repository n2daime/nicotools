# nicoids — ニコニコ動画 ID エクスポート

ニコニコ動画の **シリーズ / マイリスト / 検索結果** から動画の一覧を集めて、
**TSV（詳細）または ID のみ** で書き出す、Windows 用の小さな GUI ツールです。
Python の標準ライブラリだけで動きます（追加インストールは不要）。

## 必要なもの

- Windows
- Python 3.12（標準のインストールで OK。`tkinter` を含む）
- 追加ライブラリのインストールは不要

## 動かし方

### ダウンロードして使う

1. このページの **Code → Download ZIP** でダウンロードして展開します。
2. `nicoids.py` をダブルクリック（または `python nicoids.py`）で起動します。

### git で使う

```powershell
git clone https://github.com/n2daime/nicotools.git
cd nicotools
python nicoids.py
```

小さなウィンドウが開けば成功です。

## 使い方（3ステップ）

1. ニコニコ動画のページを開き、**アドレスバーの URL を丸ごとコピー**します。
2. ツールの **URL** 欄に貼り付けて、**「取得」** を押します。
3. 結果が出たら **「コピー」** または **「ファイルに保存」** を押します。

くわしくは **[使い方ガイド（docs/nicoids-manual.md）](docs/nicoids-manual.md)** を参照してください。

## 対応している URL

| 貼り付けるもの | 例 | ログイン設定 |
|---|---|---|
| シリーズのページ | `https://www.nicovideo.jp/series/228685` | 不要 |
| マイリストのページ | `https://www.nicovideo.jp/mylist/1754716` | **必要** |
| タグのページ | `https://www.nicovideo.jp/tag/ニコニコランキング` | 不要 |
| キーワード検索のページ | `https://www.nicovideo.jp/search/○○` | 不要 |

## マイリストを使うとき（ログイン設定）

マイリストの取得にはログインが必要です。ツールの **「ログイン設定…」** を押し、
ブラウザの Cookie にある `user_session` の値をコピーして貼り付けてください。

- **「保存する」** を押すと、`nicoids.py` と同じフォルダの `cookie.txt` に保存され、次回から自動で使われます
  （保存先は固定・内容は平文。消すときは **「ログイン情報を削除する」** または `cookie.txt` を削除）。
- **`user_session` はあなたのログイン情報そのものです。人に見せたり、GitHub などにアップロードしたりしないでください。**

## 機能と制限

- 出力形式: **TSV（詳細）** … 動画ID / タイトル / 再生数 / コメント数 / 再生時間、または **IDのみ**
- **最大件数**の指定、取得の **中断** に対応
- 検索結果は **約5,000件（157ページ）が上限**です（ニコニコ側の制限）
- 複数アカウントの使い分けは非対応です
