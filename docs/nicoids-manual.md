# nicoids 使い方ガイド

ニコニコ動画の **シリーズ / マイリスト / 検索結果** から動画の一覧を集めて、
テキスト（TSV または ID のみ）に書き出すツールです。

- インストール作業は不要です（Python の標準機能だけで動きます）。
- むずかしい設定はありません。**URL を貼り付けてボタンを押すだけ**です。
- このページは、はじめて使う人向けの説明書です。

---

## 1. これは何？

「このシリーズの動画を一覧にしたい」「このマイリストの中身を表にしたい」
「この検索結果をまとめて取りたい」というときに使います。

できること:

| やりたいこと | 例 |
|---|---|
| シリーズの動画一覧を作る | `https://www.nicovideo.jp/series/62864` |
| 自分のマイリストの一覧を作る | `https://www.nicovideo.jp/mylist/79588643` |
| タグの検索結果を一覧にする | `https://www.nicovideo.jp/tag/けものフレンズ` |
| キーワード検索の結果を一覧にする | `https://www.nicovideo.jp/search/○○` |

集めた結果は、次のどちらかで出力できます。

- **TSV（詳細）** … 動画ID・タイトル・再生数・コメント数・再生時間（Excel に貼れます）
- **IDのみ** … 動画IDを1行ずつ（別のツールに渡す用）

## 2. 準備する

### 2-1. 起動方法

`nicoids.py` があるフォルダで、次のコマンドを実行します。

```powershell
cd c:\nicotools
python nicoids.py
```

`nicoids.py` をダブルクリックしても起動できます（`.py` が Python に関連付けられている場合）。
小さなウィンドウが開けば成功です。

### 2-2. ログイン設定（マイリストを使うときだけ）

**シリーズと検索は、この準備は不要です。** マイリストを取るときだけ必要になります。

マイリストは「ログインしている人だけが見られる」ため、
ツールに「あなたがログイン済みであること」を教える必要があります。
それに使うのが `user_session` という値です。

手順:

1. ブラウザ（Chrome / Edge など）で **ニコニコ動画にログイン**する。
2. キーボードの `F12` を押して **開発者ツール** を開く。
3. **Application**（アプリケーション）タブ →
   **Cookies** → `https://www.nicovideo.jp` を選ぶ。
   - Chrome では「Storage」の中にあります。
   - Firefox では「Storage（ストレージ）」→「Cookies」。
4. `user_session` という名前の行を探す。
5. その **Value（値）** をコピーする。
   値は `user_session_12345678_xxxxxxxx…` のような長い文字列です。
6. ツールの **「ログイン設定…」** ボタンを押し、
   コピーした値を貼り付けて **OK** を押す。

値の貼り付け方は、次のどれでもかまいません（自動で読み取ります）。

- 値だけ … `user_session_12345678_xxxxxxxx…`
- `user_session=` 付き … `user_session=user_session_12345678_xxxxxxxx…`
- Cookie の行をまるごとコピーしたもの

> `user_session` を含まない文字列（別サイトの Cookie や URL など）を貼った場合は、
> 「読み取れません」と表示されて設定は変わりません。値をコピーし直してください。

> **注意**
> - この値は「あなたのログイン情報そのもの」です。
>   **人に見せたり、GitHub などにアップロードしたりしないでください。**
> - 入力した値は **ファイルに保存されません**（ツールを閉じると消えます）。
>   次に使うときはもう一度入れ直してください。
> - 値を消したいときは「クリア」を押します（`cookie.txt` を使う状態に戻ります）。
> - 値が古くなると使えなくなります。
>   そのときは手順 1〜6 をもう一度やって更新します。

#### cookie.txt を使いたい場合（任意・上級者向け）

毎回貼り付けるのが面倒な場合は、`nicoids.py` と同じフォルダに
**`cookie.txt`** というファイルを作り、値を **1行だけ** 書いておくこともできます。
ログイン設定が空のときは、このファイルが自動で使われます
（**ログイン設定に入力した値のほうが優先**されます）。

`cookie.txt` の中身の例:

```
user_session_12345678_xxxxxxxxxxxxxxxxxxxxxxxx
```

> **注意**
> - `cookie.txt` も同じくログイン情報です。**絶対に GitHub などにアップロードしないでください。**
> - 「ログイン設定…」で「クリア」を押すと、このファイルを使う状態に戻ります。

## 3. 基本の使い方（3ステップ）

1. ニコニコ動画のページを開き、**アドレスバーの URL を丸ごとコピー**する。
2. ツールの **URL** 欄に貼り付けて、**「取得」** ボタンを押す。
3. 結果が出たら、**「コピー」** または **「ファイルに保存」** を押す。

取得中は下の「状態:」の欄に `取得中… page 3（96件）` のように進み具合が出ます。
件数が多いときは少し待ってください。

---

## 4. 貼り付けられる URL

| 貼り付けるもの | 例 | ログイン設定 |
|---|---|---|
| シリーズのページ | `https://www.nicovideo.jp/series/62864` | 不要 |
| シリーズの番号だけ | `62864` | 不要 |
| マイリストのページ | `https://www.nicovideo.jp/mylist/79588643` | **必要** |
| ユーザーページ内のマイリスト | `https://www.nicovideo.jp/user/123/mylist/79588643` | **必要** |
| タグのページ | `https://www.nicovideo.jp/tag/けものフレンズ` | 不要 |
| キーワード検索のページ | `https://www.nicovideo.jp/search/○○` | 不要 |

- アドレスバーから**そのまま**貼り付けるのがいちばん確実です。
- **検索（タグ・キーワード）のときは「種類」を「自動判定」のまま**にしてください。
- 種類を自分で選びたい場合:
  - 「シリーズ」… シリーズとして取得したい
  - 「マイリスト」… マイリストとして取得したい
  - 「自動判定」… URL から自動で見分ける（ふつうはこれ）
- 検索結果の並び順や絞り込み（`?sort=f` など）は、URL に付いているとおりに取得します。

## 5. 画面の説明

```
URL: [......................................] [取得] [中断]
種類: [自動判定▼]   □ 数値のみ (so/sm を外す)      [ログイン設定…] ログイン: 未設定
出力形式: (●)TSV（詳細） ( )IDのみ   □ ヘッダ行を付ける
最大件数: [    ] 件 （空欄＝制限なし／検索は約5,000件が上限）
┌────────────────────────────────────────────────┐
│ ここに結果が出ます                                │
│                                                │
└────────────────────────────────────────────────┘
[コピー] [ファイルに保存]
状態: 12件取得しました。
```

| 部品 | 役割 |
|---|---|
| **URL** | 取りたいページの URL（またはシリーズの番号）を入れます |
| **取得** | 取りに行きます。Enter キーでも実行できます |
| **中断** | 取得を途中でやめます。**そこまでに取れた分はそのまま残ります**（取得中だけ押せます） |
| **種類** | シリーズ / マイリスト / 自動判定 |
| **数値のみ** | `so33963154` を `33963154` のように数字だけにします |
| **ログイン設定…** | マイリスト用の `user_session` を入力します（§2-2 参照） |
| **ログイン: …** | 今どのログイン情報が使われるかを表示します（下記） |
| **出力形式** | TSV（詳細）か IDのみ を選びます |
| **ヘッダ行を付ける** | 先頭に列名（動画ID・タイトル…）の行を付けます（TSV のとき） |
| **最大件数** | 指定した件数に達したら取得を終了します（空欄なら制限なし） |
| **コピー** | 結果をクリップボードにコピー（Excel やメモ帳に貼れます） |
| **ファイルに保存** | 結果をテキストファイルとして保存します |
| **状態** | 進行状況や結果、エラーを表示します |

「ログイン: …」の表示は次のとおりです。

| 表示 | 意味 |
|---|---|
| `未設定` | ログイン情報がありません（マイリストを取ると設定を促されます） |
| `設定済み（入力）` | 「ログイン設定…」で入力した値を使います |
| `設定済み（cookie.txt）` | `cookie.txt` の値を使います |
| `cookie.txt を読み取れません` | ファイルはあるが値が読み取れません |
| `要再ログイン` | 値が古くなっています（ログインし直して入れ直してください） |

## 6. 出力の見方

### TSV（詳細）

5つの項目を **タブ** で区切って並べます。

| 列 | 内容 |
|---|---|
| 動画ID | `sm...` / `so...` など |
| タイトル | 動画のタイトル（タブ・改行は半角スペース1つに整えます） |
| 再生数 | 数値 |
| コメント数 | 数値 |
| 再生時間 | `23:40` のように mm:ss（1時間以上は `1:01:01`） |

- Excel やスプレッドシートに貼り付けると、そのまま表になります。
- 「ヘッダ行を付ける」を ON にすると、先頭に列名の行が付きます。

### IDのみ

動画IDを1行ずつ並べます（例: `sm46905943`）。別のツールに渡すとき用です。

### 数値のみ

`so33963154` → `33963154`。IDのみでも TSV のID列でも適用されます。

### ファイル名

「ファイルに保存」で名前を変えなければ、次の名前になります。

- TSV（詳細） … `nicovideo.tsv`
- IDのみ … `ids.txt`

文字コードは UTF-8 で保存されます。

## 7. 便利な機能

### 最初から「取る件数」を決めておく

「とりあえず最初の100件だけ見たい」というときは **最大件数** に `100` と入れます。
その件数に達した時点で取得を終了するので、待ち時間が短くなります。

- 検索は32件ずつ取るので、`100` なら3ページ分ほどで終わります。
- 空欄なら、取れるところまで全部取ります。

### 途中でやめて、そこまでの結果を使う

件数が多くて待ちきれないときは **「中断」** を押します。
次のページの区切りで止まり、**それまでに取れた分をそのまま表示**します。
状態には `中断しました（128件）。` と出ます。

## 8. 困ったとき（Q&A・エラー早見表）

| こんなとき | 原因 | 対処 |
|---|---|---|
| 「マイリストの取得にはログイン設定が必要です」と出る | ログイン情報が未入力 | 準備の「2-2. ログイン設定」を行う |
| 「ログイン情報（user_session）が無効、または期限切れです（403）」 | ログイン情報が古い | ニコニコにログインし直し、「ログイン設定…」で値を入れ直す |
| 「○○が見つかりません（404）」 | URL や番号の間違い | アドレスバーから URL をコピーし直す |
| 「URL または ID を入力してください」 | URL 欄が空 | URL を貼り付ける |
| 「user_session を入力してください」 | ログイン設定で空のまま OK | 値を貼り付ける。`cookie.txt` を使うなら「クリア」 |
| 「貼り付けた文字列から user_session を読み取れませんでした」 | 貼り付けミス | `user_session` の値をコピーし直す |
| 「一部のみ取得」と警告が出る | 検索結果が多すぎる（後述の上限） | そのまま使う。または「最大件数」を指定して早く切り上げる |
| 「検索結果を読み取れませんでした」 | ニコニコのページ構造が変わった | ツールの更新が必要です |
| 「HTTP エラー …」が出る | 通信の一時的な問題 | 少し待って再実行する |
| コピー／保存ができない | 結果が空 | 先に「取得」を実行する |
| 日本語が表示されない・崩れる | フォントの設定 | 結果欄は自動で日本語向けフォントを選びます。崩れる場合は管理者に相談 |

### 結果が 5,000 件で止まる（重要）

ニコニコの検索結果は、**約5,000件（157ページ）まで**しか取得できません。
これを超える検索では、途中までで打ち切り、次のように表示します。

```
12,345件取得しました（全59,472件。検索の上限等のため途中で打ち切り）。
```

- これはニコニコ側の制限なので、ツールでは解除できません。
- 「最初の何件かだけ見たい」場合は、**最大件数** を指定すると素早く終わります。

---

## 9. 制限事項と今後

- **検索は約5,000件（157ページ）が上限**です。それ以上は取得できません。
- 検索は **32件ずつ** 取得するため、件数が多いと時間がかかります。
  → 「最大件数」の指定か「中断」を使うと短時間で済みます。
- **マイリストの取得にはログイン設定が必要**です（シリーズと検索は不要）。
  「ログイン設定…」に入力した値はファイルに保存されないため、開くたびに入れ直します
  （`cookie.txt` を置けば、そちらが自動で使われます）。
- **複数のアカウントを使い分けることはできません**（ログイン情報は1つだけ）。
- 検索結果の取得は、ニコニコのページに埋め込まれた情報を読んでいます。
  サイトの作りが変わると、ツール側の更新が必要になることがあります。
